VanRoute: teste da execução da rota

Três pessoas na mesma tela: o motorista inicia a trip e manda o GPS pelo WebSocket; cada pai abre o WebSocket da trip e vê só o que é dele. Cada um também recebe as próprias notificações (WebSocket /notifications). O GPS é simulado: clique no mapa do motorista ou ligue "simular GPS". Embaixo fica o log com cada chamada HTTP e cada mensagem do WebSocket (o JSON exato).

HTTP passa pelo serve.py (/api → backend)

Ida (manhã): casa → casa → escola

Volta (tarde): escola → casa → casa · outro motorista e outros pais
